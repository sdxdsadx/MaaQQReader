# 接入 MFAAvalonia 日常 GUI —— 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 MFAAvalonia v2.16.2 通过 PI V2 `interface.json` + MaaFw Python Agent 运行现有 QQReader 每日任务。

**Architecture:** `interface.json` 与 pipeline 由脚本从 `DEFAULT_TASK_CATALOG` 生成，测试保证入库文件与生成结果一致；每个任务入口是一个 `Custom` 节点，Agent 的 `QQReaderRunTask` 先跑交接检查，再以子进程运行 `scripts/run_task.py`。逻辑放在不依赖 `maa` 的 `qqreader/mfa/`，`mfa/agent/main.py` 只做胶水。

**Tech Stack:** Python 3.10、MaaFw 5.12.3（Python 绑定，仅 Agent 用）、MFAAvalonia v2.16.2（win-x64，.NET 10）。

**Spec:** `docs/superpowers/specs/2026-10-06-mfa-gui-design.md`

## Global Constraints

- Python 用 `py -3.10`；核心包 `dependencies = []` 不变；可选依赖 `mfa = ["MaaFw==5.12.3"]`。
- `qqreader/` 下任何模块都不能 `import maa`（测试环境没有 MaaFw）。
- `mfa/` 中只有 `interface.json`、`resource/`、`agent/` 入库；MFA 程序文件、`config/`、`debug/`、`logs/` 被 `.gitignore` 忽略。
- 源码与配置 UTF-8；`启动QQReaderGUI.cmd` 保持 UTF-8（现状 `chcp 65001`）。不新增 bat/cmd。
- 不写死盘符或绝对路径；路径一律相对仓库根或来自本机配置。
- 停止只按本次子进程 PID 结束（`taskkill /PID <pid> /T /F`）。
- 验证码：交接检查退出码 10（`EXIT_BLOCKED_BY_CAPTCHA`）时不启动任务，并调用 `tasker.post_stop()` 停掉整个队列。

## Review Focus

1. 书名含中文、`/`、空格时，从 MFA 输入框到 `--book-title` 参数必须原样传递，不丢字、不被 shell 拆开。
2. 用户在交接检查阶段（任务子进程还没启动）点停止，也必须结束交接子进程，并返回失败。
3. 本机配置文件缺失或无法解析时，动作要返回失败并给出中文提示，不能抛异常导致 Agent 崩溃。
4. 输入框里填了非数字或超出范围的分钟数，界面端的 `verify` 和 Agent 端的 `normalize` 都要拒绝。
5. 子进程输出中有非 UTF-8 字节时，日志转发不能中断（解码用 `errors="replace"`）。

### Task 1: Agent 动作逻辑 `qqreader/mfa/agent_action.py`

**Files:**
- Create: `qqreader/mfa/__init__.py`, `qqreader/mfa/agent_action.py`
- Test: `tests/test_mfa_agent_action.py`

**Interfaces:**
- Consumes: `qqreader.gui.task_catalog.DEFAULT_TASK_CATALOG`, `TaskSpec.fields[*].normalize`；`qqreader.gui.commands.build_run_task_command`, `build_handoff_command`；`qqreader.workflow.DailyFlowRun`, `DailyFlowRecorder`, `FlowStepSnapshot`, `apply_handoff`, `handoff_report_path`, `load_handoff_report`；`qqreader.runner.exit_codes`；`qqreader.config.load_config`。
- Produces:
  - `parse_param(raw: str | Mapping) -> tuple[TaskSpec, dict[str, Any]]`：JSON 字符串或字典；`task` 必填；未知键、未知任务、`normalize` 失败都抛 `ValueError`（中文消息）。`count` 不由动作处理（重复次数交给 MFA 的 `repeat_count`），出现时忽略。
  - `@dataclass RunResult: success: bool; exit_code: int; message: str; record_path: Optional[Path]`
  - `class TaskRunner(repo_root: Path, config_path: Path, *, popen=subprocess.Popen, log: Callable[[str], None] = print, is_stopping: Callable[[], bool] = lambda: False, kill_tree: Callable[[int], None] = <taskkill>)`，方法 `run(spec, values) -> RunResult`。
  - 常量 `ACTION_NAME = "QQReaderRunTask"`、`DEFAULT_CONFIG_RELATIVE = Path("configs/qqreader.local.json")`。

`run` 的流程：加载配置（失败时返回 `RunResult(False, 3, "未找到本机配置…请用 启动QQReaderGUI.cmd 启动")`）→ 建一个单步 `DailyFlowRun`，run_id 前缀 `mfa_` → 交接检查子进程 → 用 `apply_handoff` 判定 → 若启动，则运行任务子进程，再 `complete_current` → 保存记录。子进程等待用 0.5 秒轮询，`is_stopping()` 为真时 `kill_tree(pid)`，记 `stop_by_user`，返回 `exit_code=13`。

### Task 2: 由任务目录生成 `interface.json` 与 pipeline

**Files:**
- Create: `qqreader/mfa/interface.py`, `scripts/build_mfa_interface.py`, `mfa/interface.json`, `mfa/resource/pipeline/qqreader.json`
- Test: `tests/test_mfa_interface.py`

**Interfaces:**
- Consumes: `DEFAULT_TASK_CATALOG`, `FORMAL_PRESET_KEYS`, `TRIAL_PRESET_KEYS`；Task 1 的 `ACTION_NAME`。
- Produces:
  - `build_interface(catalog=DEFAULT_TASK_CATALOG, *, version: str) -> dict`
  - `build_pipeline(catalog=DEFAULT_TASK_CATALOG) -> dict`
  - `entry_name(key: str) -> str`，返回 `f"QQR_{key}"`
  - `scripts/build_mfa_interface.py [--check]`：写出两个文件，JSON 缩进 4、`ensure_ascii=False`、末尾换行；加 `--check` 时只比对，不一致则退出码 1。

生成规则：
- **顶层字段**：`interface_version: 2`；`name: "MaaQQReader"`；`label` / `title`: `"QQ阅读每日任务"`；`version` 取 `pyproject` 的版本号。
- **控制器与资源**：`controller: [{"name": "MuMu安卓端", "type": "Adb", "display_short_side": 720}]`；`resource: [{"name": "QQ阅读", "path": ["./resource"]}]`。
- **Agent**：`agent: {"child_exec": "python", "child_args": ["-X", "utf8", "./agent/main.py"]}`。
- **任务**：每个任务包含 `name`（`spec.name`）、`entry`、`description`、`default_check`（`spec.default_enabled`）、`option`（该任务的选项名列表）。有 `count` 字段的任务加 `repeatable: true`、`repeat_count: <count 默认值>`。
- **选项**：每个任务的每个非 `count` 字段生成一个选项，选项名为 `f"{key}.{field.key}"`。
  - `float`、`int`、`text`、`file` 类型生成 `input`。`pipeline_type` 分别为 `"double"` 和 `"int"`（数值）或 `"string"`（文本）；数值字段的 `verify` 为 `^\d+(\.\d+)?$`，文本字段无 `verify`。
  - `bool` 类型生成 `switch`。两个分支 `cases` 为 `是` / `否`，分别覆盖 `true` / `false`。
  - `pipeline_override` 写成 `{entry: {"custom_action_param": {field.key: "{" + field.key + "}"}}}`。
  - 实施前先查 PI V2 文档：确认多个选项对同一节点的 `custom_action_param` 是深合并还是覆盖。若是覆盖，则改为每个任务一个 `input` 选项，内含多个 `inputs`。在提交说明里写明采用了哪种。
- **预设**：`preset` 两项。
  - 「正式每日」：勾选 `FORMAL_PRESET_KEYS` 中的任务，参数取默认值。
  - 「1 分钟试跑」：勾选 `TRIAL_PRESET_KEYS` 中的任务，`minutes` / `duration_minutes` 设为 1，`count` 设为 1。
  - 字段格式以 PI V2 文档为准；如果 MFA v2.16.2 不支持 preset，就删掉这一项，并在 CHANGELOG 里写明。
- **Pipeline**：`{entry_name(k): {"action": "Custom", "custom_action": ACTION_NAME, "custom_action_param": {"task": k, **各字段默认值（不含 count）}}}`。

### Task 3: Agent 入口、依赖声明、启动脚本

**Files:**
- Create: `mfa/agent/main.py`
- Modify: `pyproject.toml`（`[project.optional-dependencies]` 加 `mfa`），`.gitignore`，`启动QQReaderGUI.cmd`（最后的启动段）
- Test: `tests/test_mfa_agent_entry.py`

**Interfaces:**
- Consumes: Task 1 的 `parse_param`、`TaskRunner`、`ACTION_NAME`、`DEFAULT_CONFIG_RELATIVE`。
- Produces: `mfa/agent/main.py` 中的 `check_runtime() -> Optional[str]`（返回错误消息；`maa` 不可导入，或 `importlib.metadata.version("MaaFw") != "5.12.3"` 时返回中文消息和修复命令）。

`main.py` 的流程：
1. 把仓库根（`Path(__file__).resolve().parents[2]`）插入 `sys.path`。
2. 调用 `check_runtime()`，有错误就打印并 `sys.exit(2)`。
3. 注册 `@AgentServer.custom_action(ACTION_NAME)` 类。它的 `run(context, argv)` 依次：
   - `parse_param(argv.custom_action_param)`，出现 `ValueError` 时打印并返回失败；
   - 构造 `TaskRunner(..., is_stopping=lambda: context.tasker.stopping)`；
   - 运行任务，若 `result.exit_code == 10`，调用 `context.tasker.post_stop()`；
   - 返回 `CustomAction.RunResult(success=result.success)`。
4. `AgentServer.start_up(sys.argv[-1]); join(); shut_down()`。

`.gitignore` 增加以下规则：`mfa/*` 与 `!mfa/interface.json`、`!mfa/resource/`、`!mfa/agent/`。

`启动QQReaderGUI.cmd` 的最后一段：
- `%1==classic` 时走原来的 Tkinter 启动行。
- 否则：
  - 若 `mfa\MFAAvalonia.exe` 不存在，打印“请从 https://github.com/MaaXYZ/MFAAvalonia/releases 下载 v2.16.2 win-x64 并解压到 mfa\”，或用 classic 打开旧 GUI，然后 `pause`，`exit /b 3`；
  - `%PYEXE% -c "import maa"` 失败时，打印 `%PYEXE% -m pip install "MaaFw==5.12.3"`，然后 `pause`，`exit /b 4`；
  - 都通过后，取 Python 可执行文件所在目录前置到 `PATH`，设 `PYTHONPATH=%ROOT%`，`start "" "%ROOT%mfa\MFAAvalonia.exe"`。
